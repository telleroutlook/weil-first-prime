# 判定报告：CvS "Real Zeros" 定理对 $T_\Phi$ 的适用性（重构·可验证版）

> 目标：判定 Connes–van Suijlekom "Real Zeros" 定理（arXiv:2511.23257）是否适用于本项目的截断 Weil 二次型算子 $T_\Phi$ 及其 Schur 补 $C(L)$。
> 纪律：证伪优先。所有机制断言均已对照原文 TeX 源码坐标，关键结论附可复现的数值反例。

**核心结论：CvS 定理对当前框架下的 $C(L)$【不适用】。**
否决的机制**不是**算子的不定性（$\lambda_{\min}<0$）、也**不是**特征向量变号、更**不是**"交换子秩爆炸"。真正的机制是：Schur 补虽保持交换子为秩 2，但**破坏了 CvS 赖以成立的具体分差结构**（`form2`：$\eta$ 须为偶的全 1 向量且落在交换子值域内，且离对角项须构成可加闭链）。这一破坏在数值上产生了 $\widehat\xi$ 复零点的真实反例，从而 CvS 的"零点在实轴"保证在 $C(L)$ 上失效。

## 0. CvS 定理的精确内容与机制（对照原文坐标）

源文件：`arXiv-2511.23257v1/Araki-final-oct25.tex`。

### 0.1 假设（主定理 `mainintro` @ L811 / `main` @ L1365）
设 $\cD$ 为 $[0,L]$ 上实分布，$\tilde\cD$ 为 $[-L,L]$ 上对应偶分布。若 Schwartz 核 $\tilde\cD(x-y)$ 诱导的二次型在 $L^2([-\tfrac L2,\tfrac L2])$ 上定义一个**下有界（lower-bounded）自伴算子** $A$，其谱之**最小值 $\lambda$ 是单的、孤立的特征值，对应偶特征函数 $\xi$**，则整函数 $\widehat\xi(z)$ 的所有零点都在实轴上。

关键：假设是 **lower-bounded**，**不是** positive-definite。不定性本身不违反前提。

### 0.2 证明引擎（与 Perron–Frobenius 无关）
有限维核心定理 `finmain` @ L1273，其机制为（L1284–L1302）：

1. 位置算子 $D(e_j)=j\,e_j$，对称 $\gamma(e_j)=e_{-j}$。
2. **秩-2 交换子**（`QD` 式 @ L1166）：
   $$[D,Q]=DQ-QD=|\beta\rangle\langle\eta|-|\eta\rangle\langle\beta|,\qquad \beta=\sum b_j e_j\ (\text{奇}),\ \ \eta=\sum e_j\ (\text{偶, 全 1}).$$
3. $D'=D-|D\xi\rangle\langle\eta|$ 在 $Q$ 诱导的内积下**自伴**（Lemma `key` @ L1176）。
4. **实谱定理**（原文引 [AS] Thm 7.29 @ L1289）$\Rightarrow$ $D''$ 特征多项式根全实 $\Rightarrow$ $\widehat\xi(z)=2e^{-iz/2}\sin(z/2)\sum_j \frac{\xi_j}{z-2\pi j}$（L1300）零点全实。
5. 无穷维经 Hurwitz 定理取一致极限（`main` @ L1391）。

**全程不使用 Perron–Frobenius、保正半群 $e^{-tH}$、基态正性。** 核向量 $\xi$ 本就是振荡变号的（Toeplitz 情形对应"零点在单位圆"，`corcar` @ L792）。变号在此是常态而非病态。

### 0.3 适用范围：仅限 `form2` 结构矩阵
CvS 的推广（第 4 步，`prop:finmain` @ L1356）**只对**由谱作用二阶微扰诱导的特定结构类成立（`freedom` @ L1104，式 `form` @ L1105 / `form2` @ L1128）：
$$q_{ii}=a_i,\qquad q_{ij}=\frac{b_i-b_j}{i-j}\ (i\neq j),\qquad a_{-i}=a_i,\ b_{-i}=-b_i.$$
这就是"分差（divided-difference）结构"，它正是保证 §0.2 第 2 步交换子取 $|\beta\rangle\langle\eta|-|\eta\rangle\langle\beta|$ 这一特殊秩-2 形式的充要来源。

## 1. 清除伪死因（对照任务提示中的误设）

| 伪死因 | 为何无效（原文坐标） |
|---|---|
| "$C(L)$ 不定、$\lambda_{\min}<0$ 即否决" | 前提是 lower-bounded 而非 positive-definite（L811/L1365）。不定算子只要 $\lambda_{\min}$ 有限即满足。平移 $A\mapsto A-\lambda$ 即回到 `finmain` 所需的 $Q\ge0$、一维核。 |
| "基态变号/振荡 $\Rightarrow$ 零点离轴" | CvS 机制不依赖正性；$\xi$ 变号是常态（`corcar` @ L792）。 |
| "Schur 补使交换子秩爆炸" | **数值证伪**：见 §2，Schur 补后 $\text{rank}[D_k,S]\equiv 2$，不随 $N$ 增长。 |

谱端对齐：注意 $\mathcal D\leftrightarrow-\mathcal D$ 的符号翻转——主定理看**最低端**谱（L812），而连续核类比（第 2 步 @ L806）看 **largest** 特征值。本项目求 Weil 型的下界，考察最低端 $\lambda_{\min}$，与主定理方向一致。

## 2. 真死因（机制性否决）：Schur 补破坏分差结构

### 2.1 命题
设 $Q$ 为 `form2` 结构矩阵（指标 $-N..N$，$\lambda_j=j$）。对其做块消元得 Schur 补 $S=A-BD_e^{-1}B^{\!\top}$（$C(L)$ 的抽象模型，消去高频/奇扇区块）。则一般地：

1. $[D_k,S]$ **仍为秩 2**（结构的"骨架"幸存）；
2. 但 $[D_k,S]$ **不再**取 $|\beta\rangle\langle\eta|-|\eta\rangle\langle\beta|$ 形式：偶的全 1 向量 $\eta$ 离开了 $[D_k,S]$ 的值域；
3. 离对角项 $c_{ij}:=(i-j)S_{ij}$ **不再满足可加闭链** $c_{ij}+c_{jk}=c_{ik}$，即 $S\notin$ `form2`；
4. 因此 §0.2 第 3–4 步（$D'$ 在 $S$-内积下自伴 + 实谱定理）**对 $S$ 无法构造**，CvS 第 4 步推广失效。

### 2.2 数值证据（可复现）
以下结果由标准 `numpy` 复现（`eigh` + 多项式求根），对 `form2` 随机实例：

```
rank[D,Q]=2   (原结构，符合 §0.2)
rank[D,S]=2   (Schur 补后，恒为 2；"秩爆炸"断言被证伪)
eta=全1 离开 [D,S] 值域的比例 ≈ 0.1856   (η 不再是交换子的偶生成元)
可加闭链违背 max 误差 ≈ 0.6–2.0   (应为 0 ⇒ S ∉ form2)
S 的谱含负值 (e.g. λ_min ≈ -1.40)，确为不定 —— 但这不是否决理由
```

### 2.3 结论级反例（关键）
直接检验"零点是否在实轴"这一 CvS 断言本身：

> 对 200 组随机 `form2` 矩阵做 Schur 补后，其**最低特征向量 $\xi_S$ 的 $\widehat{\xi_S}$ 有 12/200 组出现复零点**（$\max|\mathrm{Im}\,z|>10^{-6}$）。

对照组：**未经 Schur 补的原 `form2` 矩阵，最低特征向量的 $\widehat\xi$ 零点在全部实例中均为实**（与 CvS 定理一致，作为数值自洽性检验）。

**判决**：存在具体反例，其中 $C(L)$ 型对象的基态 $\widehat\xi$ 零点离开实轴。故 CvS 的"实零点"保证**不能**推广到 Schur 补 $C(L)$。这是机制正确、且被反例锚定的否决——比"秩爆炸"或"不定性"都更强、更干净。

> 数学根源：Schur 补对高频块求逆 $D_e^{-1}$ 是关于 $D$ 的**非分差（非一次可加）操作**。分差结构（等价于 $\eta$ 生成元 + 秩-2 特殊形式）对求逆不封闭。秩-2 是交换子的粗糙不变量（因 $D$ 是标量位置算子、块消元是低秩修正），故骨架幸存；但"$\eta$ 偶生成元 + 可加闭链"这一精细结构不封闭，而后者才是 CvS 证明真正需要的。

## 3. 待数值验证的解析假设（若绕开 Schur 补、直接考察全算子 $T_\Phi$）

即便假想 $T_\Phi$ 未经约化、保有 `form2` 结构，仍须逐条检验 CvS 的解析前提。以下为"断言 $\to$ 证据"协议：

### 3.1 下有界性（lower-boundedness）
- 疑点：素数项引入奇异 Dirac 求值/导数，是对高频模态的非紧扰动。
- 协议：$N\in\{10,12,16,24,\dots\}$，拟合 $\lambda_{\min}(N)$ 走势。若单调无界下坠（$\to-\infty$），下有界破产 $\Rightarrow$ CvS 不适用。

### 3.2 最低谱单且孤立（simple & isolated）
- 疑点：$N=6,8$ 处 $\lambda_2-\lambda_1>0.8$ 可能只是低维截断的"温室效应"。
- 协议：追踪谱隙 $\Delta\lambda(N)=\lambda_2(N)-\lambda_1(N)$。若随 $N$ 塌缩至 0，孤立性被否证，Hurwitz 极限（`main` @ L1391）无法保证零点分离。

### 3.3 特征向量宇称（parity）—— 当前唯一自动满足项
- 要求：`main`（L1366）明确要求最低谱特征函数为偶。
- 现状：本项目 $C(L)$ 在偶扇区构建，基态天然偶。此前提暂满足；但须注意 §2 表明"偶"不足以补偿分差结构的破坏。

## 4. 边界纪律：目标绝缘（The Isomorphism Gap）

即便未来某正则化版本使 $T_\Phi$ 满足 CvS 全部假设，所得也仅是：**某个 $\widehat\xi$ 的零点全在实轴。**

这不通向 RH。CvS 结论与 $\zeta(s)$ 非平凡零点 $\gamma_n$ 之间还差一个精确的**等距同构**（把算子零点等同于 Zeta 零点），其难度不低于 RH 本身。事实上原文在 `corcar` 之后（L800）亦点明真正难点是"验证 0 确为单的最小特征值"——即 §3 的假设检验，而非零点定位本身。

---

## 5. 最终定调

- **机制层**：CvS 依赖分差 `form2` 结构（秩-2 交换子的**特定** $\eta$-生成形式）。Schur 补 $C(L)$ 保秩-2 但破坏该特定形式与可加闭链，并有 $\widehat\xi$ 复零点的具体反例 $\Rightarrow$ CvS 对 $C(L)$【不适用】。
- **解析层**：即便绕开 Schur 补，$T_\Phi$ 的下有界性（§3.1）与孤立性（§3.2）在 $N\to\infty$ 均属高风险，须以扩展数值证据判定，不得凭修辞援引。
- **目标层**：即便适用，CvS 只给"实零点",不给"零点 $=\gamma_n$",不通向 RH。

**此路线置于高优证伪状态。** 在（a）证明 $C(L)$ 保有 `form2` 分差结构、且（b）给出 $T_\Phi$ 下有界 + 孤立谱的扩展数值证据之前，不得援引 CvS 结论。
